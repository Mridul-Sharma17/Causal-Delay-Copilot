# Artefact Composition

This context renders checked draft artefacts from sanitized structured inputs. It may change presentation, but it has no authority to invent facts, actions, or causal claims.

## Language

**Drafted Artefact**:
An unsent, versioned communication or decision note grounded exclusively in allow-listed evidence and recommendation data for manager review. It has no operational effect until authorized.
_Avoid_: Final Communication, Sent Message, Action
